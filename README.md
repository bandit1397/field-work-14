# 현장 업무처리 14종

지역경찰 현장 경찰관이 쉽게 참고할 수 있도록 만든 **실전 업무처리 매뉴얼**입니다.
[민감사건 체크리스트(Sensitive-case)](https://github.com/bandit1397/Sensitive-case) 형식을 참고하여 제작했습니다.

## 사용 방법

- **웹에서 바로 보기**: <https://bandit1397.github.io/field-work-14/>
- 표지 화면을 누르면 매뉴얼로 진입합니다.
- `PART 선택 → 절차 선택 → 세부 항목 버튼` 순으로 눌러 내용을 펼쳐 봅니다.
- `원본 자료 보기`에서 원본 인포그래픽 이미지를 확인할 수 있습니다.

## 색상 표기 규칙 (`index.html`의 `세부내용Depth` 데이터)

| 표기 | 화면 색상 | 의미 |
|------|-----------|------|
| `\|텍스트\|` | 빨강 | 강조 / 주의 |
| `\|\|텍스트\|\|` | 파랑 | 핵심 용어 / 서류명 |
| `\|\|\|텍스트\|\|\|` | 초록 | 실무 팁 / 예외 |

`depth` 값(0, 0.5, 1, 1.5, 2)으로 들여쓰기와 글자 크기가 조절됩니다.

## 새 PART / 항목 추가 방법

1. `index.html`의 `파트정보` 객체에 새 PART의 `부제 · 절차 · 원본` 목록을 추가합니다.
2. `PART 선택` 영역(`input[name="part"]`)에 라디오 항목을 추가합니다.
3. `세부내용Depth` 객체에 각 절차(`value`)별 세부 항목을 추가합니다.
   `필수서류` 키는 `3. 필수서류` 버튼 전용으로 예약되어 있습니다.
4. 원본 이미지가 있으면 저장소에 넣고 `파트정보`의 `원본` 배열에 `{ file, label }` 을 추가합니다.
